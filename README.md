# Dublist | Curated Wishlists

**Status: Work in progress**

A front-end prototype for an editorial-style personal shopping and family wishlist experience, originally titled Wade List. The project explores visual browsing and carefully structured product details rather than a conventional list view.

**Prototype:** https://dubstitch.github.io/dublist/

## Built so far

- Homepage and men's and women's curated collection pages
- Scroll-driven category changes with responsive mobile behavior
- Product carousels and detail modals
- Item recipients, wishlists, descriptions and product metadata
- Modular CSS and vanilla JavaScript with product data separated into JSON files

## Technology

HTML, CSS, JavaScript modules and JSON. This is a static front-end prototype and has no build step or commerce backend.

## Content and limitations

The product catalog includes sample entries, placeholder illustrations and links such as `example.com` alongside selected product photos. Prices and shopping links are prototype data, not current listings. This is **not a completed storefront**, payment service or production-ready shopping application.

## Structure

- `index.html`: homepage
- `women.html`, `men.html`: category experiences
- `assets/css/`: styles
- `assets/js/`: modular interface logic
- `data/`: structured catalog and navigation data
- `assets/images/`: image and illustration assets
